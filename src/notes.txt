To improve flexibility and readability, you can divide the code into multiple classes and structs, 
    each responsible for a specific aspect of the Vulkan setup and rendering process. Here's a suggested 
    structure:

 - Window Management: A class to handle window creation and management.
 - Vulkan Instance: A class to handle Vulkan instance creation, validation layers, and debug messenger.
 - Physical Device: A class to handle physical device selection and querying.
 - Logical Device: A class to handle logical device creation and queue retrieval.
 - Swap Chain: A class to handle swap chain creation and management.
 - Pipeline: A class to handle graphics pipeline creation.
 - Buffers: A class to handle buffer creation and management (vertex, index, uniform).
 - Descriptors: A class to handle descriptor set layout and descriptor sets.
 - Command Buffers: A class to handle command buffer allocation and recording.
 - Synchronization: A class to handle synchronization objects (semaphores, fences).
Here's a basic outline of how you can structure these classes:
